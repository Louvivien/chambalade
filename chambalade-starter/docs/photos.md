# Photos

Originaux : dossier Google Drive « Biblio Photos »
(https://drive.google.com/drive/folders/1OT86SLrY2yCn34d_TXJOPhYH910I8oZJ), à télécharger
dans `photos-originales/` (non versionné). Le script `scripts/convertir-photos.mjs` les
convertit (HEIC compris) en JPEG de 2560 px de large maximum, sans métadonnées, dans
`src/assets/photos/` sous le nom « Fichier cible ».

N'utiliser que les photos au statut « À utiliser ». Les autres attendent un original ou une
validation : prévoir l'emplacement avec une photo de remplacement de la liste.
